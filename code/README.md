# Prozessvorhersage mittels Transformer-Netzen am Beispiel der Fischertechnik APS

> Process Prediction using the Transformer architecture: Case Study on a Fischertechnik APS

This directory contains all the code and relevant documentation to deploy the transformer network on the MQTT data of the Fischertechnik APS. It focuses on providing the documentation to reproduce the results of the thesis.

To get started with using the scripts, go into the [scripts directory](scripts/README.md).
